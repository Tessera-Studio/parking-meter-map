## 1. 方針

- **地図が主役。** 画面のほとんどを地図にし、上に検索、下に区間のカード（横にめくる）だけを置く。今の「一覧シート（画面の44%）」はやめる。カードは地図を隠さない大きさにする（§5）。
- **状態は色だけで伝える。** 緑＝その時刻に使える区間、赤＝時間外の区間、グレー＝時間不明の区間。
- **区間は道路に沿った線で見せる。** 線は必ず出す。Pマークは、選んだ区間と、十分に寄った地図のときだけ出す（地図の上に物を増やさない）。
- **「何時まで」はカードのバッジに任せる。** 地図の上には時刻の札を出さない。
- 見た目：白い角丸カード＋薄い影。黒い枠線と四角い部品はやめる。アクセントは緑（時間外は赤、選んだ区間だけ `--pick`）。オレンジは使わない（赤と紛らわしいため）。

## 2. 文言のルール（重要）

- 「いま停められる」「停められます」「停められない」「停められません」は**画面のどこにも出さない**。
- 緑の区間のバッジ：**終わりの時刻だけ**。例「21:00まで」
- 時間外の区間のバッジ（赤）：**次に使える時刻だけ**。例「あす 9:00から」「土曜 9:00から」。見つからないときは「冬期休止中」
- 時間不明（`avail()==='unk'`）のバッジ（グレー）：「時間は現地で確認」
- 詳細の時間表の見出しは「利用できる時間」、使えない行は「利用不可」
- 「あと◯分」の表示（今のオレンジの枠）はやめる

`status()` / `verdict()` / `week()` / `rowHtml()` の文言をこのルールに合わせて書き換えること。

## 3. デザイン・トークン

```css
:root{
  --ground:#ECEAE4;      /* 地図の地の色・画面の地 */
  --surface:#FFFFFF;     /* カード・シート */
  --surface-2:#F5F4F1;   /* カード内の小さな枠（最大・料金など） */
  --chip-2:#F1F1EF;      /* サブボタン（詳細・車の場所を確認） */
  --line:#ECEAE4;        /* 区切り線 */
  --ink:#1C1D1F;
  --ink-2:#4A4D52;
  --muted:#6B6F75;
  --ok:#1E7F4A;          /* 緑。白文字を載せて読める濃さ */
  --no:#C8372D;          /* 赤＝時間外の線・P・バッジの文字。白文字を載せて読める濃さ */
  --no-wash:#FBE4E2;     /* 赤のバッジの地 */
  --off:#A3A8AE;         /* グレー＝時間不明の線・P */
  --off-wash:#E6E7E9;    /* グレーのバッジの地 */
  --here:#2F6FDB;        /* 現在地 */
  --pick:#F2B300;        /* 選んだ区間の線。緑・赤・グレー・現在地の青とぶつからない色 */
  --pick-edge:#1C1D1F;   /* 選んだ区間の線の縁（明るい地図で黄色を締める） */
  --r-card:18px; --r-ctl:14px; --r-btn:12px; --r-badge:8px;
  --shadow-card:0 4px 18px rgba(0,0,0,.14);
  --shadow-ctl:0 2px 10px rgba(0,0,0,.12);
  --f-body:"Zen Kaku Gothic New","Hiragino Sans",system-ui,sans-serif;
}
```

ダークテーマは、地・カードを暗く（例 `--ground:#141516; --surface:#1E2022; --surface-2:#26292C; --ink:#F2F2F2; --ink-2:#D0D0D0; --muted:#A6A6A6`）、`--ok` は明るめ（`#4FC983`、ただしその上の文字は黒）、`--no` も明るめ（`#FF6B5E`、その上の文字は黒）、`--no-wash` は `#3B2321` にする。`--pick` は `#FFC93C`、`--pick-edge` は使わない（暗い地図では縁なしで十分目立つ）。

文字の大きさ：カードの区間名 20px/700、カードの補足 13px、バッジ 13px/700、検索 16px。数字は `font-variant-numeric: tabular-nums`。

## 4. 地図の描き方（`draw()`）

### 4.1 線（いつも出す）

| 状態 | 線 |
|---|---|
| 緑（`ok`） | 太さ6pxの `--ok`、下に10pxの白い縁（ダークテーマでは縁なし） |
| 赤（`no`） | 太さ4pxの `--no`、縁なし |
| 時間不明（`unk`） | 太さ4pxの `--off` の破線（4 6） |
| **選んだ区間** | 太さ8pxの `--pick`、下に12pxの `--pick-edge` の縁（ダークテーマでは縁なし）。状態に関係なく同じ色 |

- 選んだ区間の状態（緑・赤・グレー）は、カードのバッジと、下のPマークの色で伝える。線の色は「選んでいる」ことだけを表す。
- 重なり順：時間不明 → 赤 → 緑 → 選んだ区間。
- 赤は緑より細くして、緑が先に目に入るようにする。
- 線は押せる。細い線には見えない太い当たり判定（18px程度）を重ねる。
- `SMALL_ZOOM` より引いた地図では、線を細くする（緑4px・赤2px・時間不明2px、白い縁なし）。線は省かない。

### 4.2 Pマーク（出す場面を絞る）

| 地図の縮尺 | Pマーク |
|---|---|
| `DETAIL_ZOOM`（17）未満 | **選んだ区間だけ** |
| `DETAIL_ZOOM` 以上 | 全区間に小さいPマーク＋選んだ区間に大きいPマーク |

- Pマークの地の色：緑なら `--ok`、時間外なら `--no`、時間不明なら `--off`。
- 選んだ区間のPマーク：32px角・角丸9px・状態の色の地に白い「P」・白い縁3px・`--shadow-ctl`・下に小さな三角。`z.center` に置く（Leaflet の `divIcon`）。
- 寄ったときの小さいPマーク：18px角・角丸5px・状態の色の地に白い「P」・白い縁2px。重なり順は 時間不明 → 赤 → 緑（緑が一番上）。押せる（線と同じ区間を選ぶ）。
- **地図の上に時刻の札（「〜21:00」など）は出さない。** 何時まで使えるかはカードのバッジだけで見せる。

### 4.3 そのほか

- 線・Pのどちらを押しても、その区間を選び、カルーセルをそのカードまで動かす。あわせて、その区間を地図の見えている範囲（上の検索欄とカードを除いた部分）のまん中に動かす。カードをめくって選んだときは、端に近いときだけ少し動かす。
- 下地は OpenFreeMap（OpenMapTiles）のベクトル地図を MapLibre GL JS で描く（`basemap.js`、ライブラリは `vendor/` に同梱、鍵は不要）。
  - 配色は `basemap.js` で決める。明るい配色とダークテーマ用の暗い配色の2つ。画像の色を反転して暗くすることはしない。
  - **駅名・大きな施設名・地名のラベルは残す**こと（場所の手がかり）。シンプルは地名・駅名・大きな道の名前だけ、詳しい地図は建物・施設名・細い道の名前も出す。
  - WebGL が使えない、または地図が読めないときは、国土地理院の淡色地図（画像）に切り替える。
- 現在地：20pxの `--here` の丸、白い縁3px、まわりに薄い青の輪。

## 5. メイン画面

上から順に：

1. **検索欄**（左16px・右78px・上は safe-area + 12px、高さ52px、角丸14px、白、`--shadow-ctl`）。虫めがねアイコン＋プレースホルダ「行き先・駅名で探す」。今の国土地理院の地名検索をそのまま使う。
2. **タイマーボタン**（検索欄の右、52px角・角丸14px・白・時計アイコン、`aria-label="タイマー"`）。押すとタイマー画面（§9）。
3. **現在地ボタン**：右下、カードの上。48pxの白い丸。
4. **カードの列**（下から16px）：横スクロール＋`scroll-snap`。カード幅330px、間10px、左16px。次のカードが少し見える。

**地図の切り替えボタン（シンプル／詳しい）** はキャンバスに無いが機能は残す。現在地ボタンの上に同じ大きさの白い丸ボタン（レイヤーのアイコンのみ）として置く。

日時の指定（「いま ◯:◯◯ ▾」）と「緑だけ」のチップは置かない。使えるかどうかはいつも「いま」で判定し、1分ごとに見直す。

### カードの中身（4行・高さ180pxまで）

```
[P] 有楽町二丁目                 [きょう 9:00から]   ← Pの色とバッジで状態
メーター · 徒歩1分 · 最大1時間 · 300円        1/40
9:00–19:00 · 日曜・休日、1/1–3 を除く
[ ➤ ここへ行く               ] [ 詳細 ]
```

- **大きさ**：内側の余白14px、行の間6px。カードの高さは最大180px。390px幅のスマホで、地図が画面の高さの7割以上見えること。
- 1行目：Pアイコン（26px角・角丸7px・状態の色の地に白い「P」）、区間名（20px/700、長いときは末尾を「…」）、右端にバッジ。
- 2行目：種類・徒歩◯分・最大・料金を「·」でつなぐ（13px、`--muted`）。右端に件数「1/40」。
- 3行目：利用時間と除外を1行で（13px、`--muted`、はみ出したら「…」）。除外がなければ「毎日 9:00–21:00」。除外があれば「9:00–19:00 · 日曜・休日、1/1–3 を除く」。**警告アイコン・オレンジの文字は使わない。** 時間不明の区間はこの行を出さない。
- 4行目：ボタン（高さ44px）。「ここへ行く」（`--ink` 地に `--surface` 文字、ダークテーマでは逆）と「詳細」（`--chip-2` 地）を**同じ幅**で横に並べる。
- **カードに置かないもの**：利用時間・最大・料金を大きな数字で並べる段、区切り線、「〜を除く」を1行ずつ並べる注意書き。これらは詳細（§7）に置く。
- バッジ：緑は `--ok` 地に白文字＋時計アイコン。赤は `--no-wash` 地に `--no` 文字。グレーは `--off-wash` 地に `--ink-2` 文字。
- 赤・グレーの区間のカードは、区間名を `--ink-2` に落とす。
- 「徒歩◯分」＝距離(m)÷80 を切り上げ。距離は地図の中心（行き先があるときは行き先）から区間の線までの最短距離（今の `nearest()`）。
- 並び順：緑を近い順、その後に赤とグレーをまとめて近い順。件数は今の `NEAR_M`（1km）以内、最大 `LIST_MAX`。
- カードを横にめくると、その区間を選んだ状態にして地図を少し動かす。地図の線やPを押すと、そのカードまでカルーセルを動かす。
- 「ここへ行く」→ §8。「詳細」→ §7。

### 広い画面（761px以上）

カードを左の列（幅400px）に縦に並べる。上の検索欄・タイマーボタンは地図の上（左列の右）に置く。

## 6. 行き先を入れたとき

- 地名検索で候補を選ぶと「行き先モード」：検索欄に名前を表示し、左を「戻る」矢印、右に「×」（行き先を消す）。
- 行き先に黒い丸のマーカー（白い旗アイコン）と、下に黒い札で名前。
- 行き先を中心に半径400mの破線の円と、円の上に白い札「徒歩5分」。
- カードの上に白い小札「歌舞伎座の近く **5か所**（近い順）」。
- カードの距離表示は「歌舞伎座まで 徒歩3分」（区間から行き先まで）。

## 7. 区間の詳細

- 上の約236pxは地図（選んだ区間を中央に）。左上に白い丸の「戻る」ボタン。
- 閉じ方は3つ：左上の「戻る」、シート右上の「×」（40pxの丸、`--chip-2` 地）、端末の「戻る」（Android の戻るボタン・iPhone のスワイプ）。開くときに履歴を1つ積み、どれで閉じても地図の画面に戻る（ページからは出ない）。
- その下に白いシート（上の角丸24px）。中身：
  1. 小さく「東京都中央区 · パーキング・メーター」、大きく区間名（28px/700）、右に「徒歩 2分」
  2. **状態ブロック**：緑のときは `--ok` 地に白文字で「21:00まで」（24px/700）と「1回 最大1時間」。時間外は `--no-wash` 地に `--no` 文字で「あす 9:00から」。時間不明は `--off-wash` 地で「時間は現地で確認」と「県警の公開情報に時間・曜日がありません」。
  3. 3つの数字：**利用時間／最大／料金**を横に並べる。それぞれ上に線のアイコン（時計・ストップウォッチ・円）、真ん中に大きな数字（20px/700）、下に小さなラベル（12px、`--muted`）。`--surface-2` 地の1枚の枠に入れる。車種は「区間の情報」に移す。
  4. 「利用できる時間」：曜日ごとの時間が全部同じなら「毎日 9:00–21:00」の1行にまとめる。違うときだけ曜日別の行。その下に、除外を1行ずつ「日曜・休日を除く」「1月1日〜3日を除く」（13px、`--ink-2`、アイコンなし）。冬期など使えない期間も同じ形。
  5. 注意（アイコン付き、13px）：「時間外は、ほとんどの区間で駐車禁止です。現地の標識・メーターの表示が優先されます。」
  6. 出典ラベル：
     - 東京：`[公式データ]` 警視庁 オープンデータ（2026年4月）
     - 大阪：`[おおよその位置]` 大阪府警察の資料から作成
     - 神奈川など時間不明：`[時間は現地で確認]` 神奈川県警察
     - 札幌・京都：`[公式データ]` 各警察の公開情報
  7. 「地図アプリで経路を見る」：「Apple マップ」「Google マップ」の2行。**「ここへ行く」のシート（§8）と同じ見た目・同じ大きさ**（56–60px、`--surface-2` 地、地図アイコン＋右に「›」）。並びも §8 と同じ（iPhone/iPad は Apple を上）。押すとその地図で経路を開く（覚えた地図は使わず、いつも両方を出す）。

## 8. 「ここへ行く」

- 初回だけ下からシートを出す（地図は暗く）：
  - 見出し「銀座三丁目へ案内します」
  - 「車で約6分 · 14:08ごろ着」＋緑バッジ「21:00まで」
    - 所要時間の目安：直線距離×1.4 を時速20kmで割る（分、切り上げ）。
    - 到着予想が終わりの時刻を過ぎるときは、バッジを赤にして「着くころには時間外」。
  - 「どの地図で案内しますか」：行が2つ（56–60px、`--surface-2` 地）「Apple マップ」「Google マップ」。アイコンは汎用の地図アイコンで、各社のロゴは使わない。
  - チェックボックス「次からはこの地図ですぐ開く」（初期オン）
  - 「やめる」
- 選んだ地図を `localStorage` に覚え、2回目からはシートを出さずに直接開く。詳細画面のリンクは常に両方使える。
- 既定の並び：iPhone/iPad は Apple を上、それ以外は Google を上。
- 開くURL（目的地は区間の `z.center`）：
  - Google：`https://www.google.com/maps/dir/?api=1&destination=${lat},${lng}&travelmode=driving`
  - Apple：`https://maps.apple.com/?daddr=${lat},${lng}&dirflg=d`
- **カードのボタンは「ここへ行く」のまま切り替えない**（区間に着いても「停めた」などには変えない）。

## 9. タイマー

右上の時計ボタンから開く全画面のビュー（ページ遷移ではなく、地図の上に重ねる）。左上の「∨」で閉じる。

- 上：状態の札（動いているとき緑「駐車中」、止まっているときグレー「タイマー」）、区間名（26px/700）、「東京都中央区 · パーキング・メーター」
  - 区間は、スタートした時点で選んでいた区間。何も選んでいなければ現在地にいちばん近い区間。
- 中央：直径260pxの円（太さ16px、地 `--line`、残りを `--ok`）。中に「あと」「42分」（64px/700）「15:05 まで」。
  - 止まっているときは円をいっぱいにして「1時間」と、その区間の最大時間を出す。
- 2つの小枠：「停めた時刻 14:05」「最大 · 料金 1時間 · 300円」
- 通知の切り替え：「終わる10分前に知らせる」（オン／オフ）、小さく「ホーム画面に追加すると、画面を閉じていても届きます」
- 下のボタン：
  - 横に2つ並べる：**「スタート」**（緑・再生アイコン）と **「ストップ」**（黒・四角アイコン）。動いている間はスタートを薄くして押せなくし、止まっている間はストップを薄くする。
  - その下に「車の場所を確認」（`--chip-2` 地・ピンのアイコン）：タイマー画面を閉じ、スタートした時点の現在地（取れなければ区間の中心）に地図を寄せて、車のマーカーを出す。
  - 一番下に小さく「メーター・チケットに表示された時刻が優先です」
- 「出庫した」ボタンは置かない。
- 状態は `localStorage` に保存（`{zoneId, startedAt, limitMin, carLatLng}`）し、再読み込みしても続く。最大時間が分からない区間は60分。
- 通知：`Notification` の許可があれば、終わる10分前に1回出す。許可がない／使えないときは画面上の表示だけ。
- 時間になったら円を空にし、「時間です」と出す（色は `--no`）。

## 10. 近くに緑がないとき（夜など）

- 地図は赤（と時間不明のグレー）の線だけになる（選んだ区間だけ `--pick`）。
- カードは赤の区間を近い順に出す（バッジ「あす 9:00から」）。
- カードのボタンはほかと同じ「ここへ行く」（黒地）と「詳細」。「あす 9:00 で見る」「近くの駐車場」のボタンは置かない。カードの大きさは §5 と同じ。
- 「0区間」の大きな表示や「この近くで停められる区間はありません」の文章は出さない。

## 11. 消すもの

- 一覧シート（`.sheet`、`grip`、`sum`、凡例 `key`、`notice`、`renderList()` の今の形）→ カード列に置き換え
- 「あと◯分」のオレンジの枠（`.soon`）
- 黒い1.5pxの枠線、角2pxの部品
- 日時の指定・「緑だけ」のチップ（改訂で削除）
- 地図の上の時刻の札（「〜21:00」）
- カードの中の、利用時間・最大・料金の大きな数字の段と、オレンジの「〜を除く」の行（詳細へ移す）

## 12. 変えないもの

- データ（`data/zones.geojson`、`zones.js`、`data/holidays.json`）と判定ロジック（`avail()`、`nextOpen()`、`Zones.openNow()`）
- 地名検索・逆引き（国土地理院）
- 最初に見せる場所（現在地 → 前回の場所 → 銀座）
- 出典の表示（地図の右下）
- `build/stamp.py` でのキャッシュ番号付け（画面のファイルを変えたらコミット前に実行）
