## 1. 方針

- **地図が主役。** 画面のほとんどを地図にし、上に検索欄と「？」ボタン、下（広い画面では左）に区間のカードだけを置く。カードは地図を隠さない大きさにする（§5）。
- **いつも明るい。** 端末がダークテーマでも、地図・カード・シート・ボタンとも明るい配色のまま。ダークテーマ用の配色は持たない。
- **テーマ色は「標識の青」。** 駐車可の標識（青地に白のP）と、アプリのアイコンと同じ紺 `--brand`（#1E4E8C）。押す主なボタン（ここへ行く・スタート・購入）・鍵の印・有料プランのシート・フォーカスの輪に使う。
- **状態は色だけで伝える。** 緑＝いま使える区間、赤＝時間外の区間、グレー＝時間不明の区間。選んだ区間だけ黄。**緑は状態にだけ使い、ボタンや飾りには使わない**（「緑のボタン」が「使える」と紛れないように）。
- **区間は道路に沿った線で見せる。** 線はいつも出す。Pマークは選んだ区間と、十分に寄った地図のときだけ（地図の上に物を増やさない）。
- **「何時まで」はカードのバッジに任せる。** 地図の上には時刻の札を出さない。
- **判定はいつも「いま」。** 日時を指定する機能は置かない。1分ごとに見直す。
- 見た目：白い角丸カード＋薄い影。黒い枠線と四角い部品は使わない。オレンジは使わない（赤と紛らわしいため）。

## 2. 文言のルール（重要）

- 「いま停められる」「停められます」「停められない」「停められません」は**画面のどこにも出さない**。
- 緑の区間のバッジ：**終わりの時刻だけ**。例「21:00まで」
- 時間外の区間のバッジ（赤）：**次に使える時刻だけ**。例「あす 9:00から」「土曜 9:00から」。見つからないときは「冬期休止中」
- 時間不明（`avail()==='unk'`）のバッジ（グレー）：「時間は現地で確認」
- 詳細の時間表の見出しは「利用できる時間」、使えない行は「利用不可」
- 「あと◯分で時間外」のような表示は出さない（タイマーの残り時間は別。§9）

  --surface-2:#F5F4F1;   /* カード・シート内の小さな枠 */
  --chip-2:#F1F1EF;      /* サブボタン（詳細・車の場所を確認・×） */
  --line:#ECEAE4;        /* 区切り線・タイマーの円の地 */
  --ink:#1C1D1F;  --on-ink:#FFFFFF;
  --ink-2:#4A4D52;
  --muted:#6B6F75;
  --brand:#1E4E8C; --on-brand:#FFFFFF; /* テーマ色・標識の青（主なボタン・鍵・有料プラン） */
  --brand-2:#163C6E;                 /* 押したときの紺 */
  --brand-wash:#E7EDF6;              /* 紺の淡い地（有料プランの機能のアイコン・札） */
  --ok:#1E7F4A;   --on-ok:#FFFFFF;   /* 緑（バッジ・状態・タイマーの残り）。ボタンには使わない */
  --no:#C8372D;   --on-no:#FFFFFF;   /* 赤（バッジの文字・時間切れ） */
  --no-wash:#FBE4E2;                 /* 赤のバッジ・状態の地 */
  --off:#A3A8AE;                     /* グレー */
  --off-wash:#E6E7E9;                /* グレーのバッジ・状態の地 */
  --here:#1E4E8C;                    /* フォーカスの輪（テーマ色） */

  /* 地図の上に描くもの */
  --map-ok:#1E7F4A;      /* 緑の線・P */

  --map-off:#A3A8AE;     /* 時間不明の線・P */
  --map-pick:#F2B300;    /* 選んだ区間の線（緑・赤・グレー・現在地の青とぶつからない色） */

  --map-here:#2F6FDB;    /* 現在地 */

  --r-card:18px; --r-ctl:14px; --r-btn:12px; --r-badge:8px;
  --shadow-card:0 4px 18px rgba(0,0,0,.14);
  --shadow-ctl:0 2px 10px rgba(0,0,0,.12);

- `color-scheme: light`。`prefers-color-scheme: dark` で色を変える処理は置かない。
- 数字は `font-variant-numeric: tabular-nums`。

## 4. 地図

### 4.1 下地

- OpenFreeMap（OpenMapTiles）のベクトル地図を MapLibre GL JS で描く（`basemap.js`。ライブラリは `vendor/` に同梱、鍵は不要）。配色は `basemap.js` の明るい配色だけ。
- 地図は1種類（地名・駅名・大きな道の名前だけを出す、色を抑えた配色。区間の線とPマークが目立つ）。切り替えのボタンは置かない。
- 駅名・町名・大きな施設名のラベルは残す（場所の手がかり）。
- WebGL が使えない、または地図が読めない（8秒たっても1枚も届かない・その前に失敗した）ときは、国土地理院の淡色地図（画像）に切り替える。
- 地図に CSS の filter（暗くする・色を反転する）はかけない。
- **出典は地図の上に出さない**（カードと重なるため）。区間データ・地図（OpenFreeMap・OpenMapTiles・OpenStreetMap、画像の地図のときは地理院タイル）・検索の出典は、右上の「？」のメニュー（§5）にまとめる。

### 4.2 区間の線（いつも出す）

| 状態 | 線 |
|---|---|
| 緑（`ok`） | 太さ6pxの `--map-ok`、下に10pxの白い縁 |
| 赤（`no`） | 太さ4pxの `--map-no`、縁なし |
| 時間不明（`unk`） | 太さ4pxの `--map-off` の破線（4 6） |
| **選んだ区間** | 太さ8pxの `--map-pick`、下に12pxの `--map-pick-edge` の縁。状態に関係なく同じ色 |

- 選んだ区間の状態（緑・赤・グレー）は、Pマークの色とカードのバッジで伝える。線の色は「選んでいる」ことだけを表す。
- 重なり順：時間不明 → 赤 → 緑 → 選んだ区間。赤は緑より細くする。
- 細い線にも押せるよう、見えない太い当たり判定（18px）を重ねる。
- `SMALL_ZOOM`（14）より引いた地図では線を細くする（緑4px・赤2px・時間不明2px、白い縁なし）。線は省かない。

### 4.3 Pマーク

| 地図の縮尺 | Pマーク |
|---|---|
| `DETAIL_ZOOM`（17）未満 | **選んだ区間だけ** |
| `DETAIL_ZOOM` 以上 | 全区間に小さいPマーク＋選んだ区間に大きいPマーク |

- 地の色：緑なら `--map-ok`、時間外なら `--map-no`、時間不明なら `--map-off`。中の「P」は白。
- 選んだ区間：32px角・角丸9px・白い縁3px・`--shadow-ctl`・下に白い小さな三角。`z.center` に置く（Leaflet の `divIcon`）。
- 寄ったときの小さいP：18px角・角丸5px・白い縁2px。重なり順は 時間不明 → 赤 → 緑。押せる。
- **地図の上に時刻の札（「〜21:00」など）は出さない。**

### 4.4 押したとき・そのほか

- 線・Pのどちらを押しても、その区間を選び、カードの列をそのカードまで動かし、その区間を地図の見えている範囲（上の検索欄と下のカード、広い画面では左の列を除いた部分）のまん中に動かす。カードの並びは変えない。
- カードの列を自動で動かしている途中は、途中のカードを選び直さない（人がカードに触れたら、その操作を優先）。
- 現在地：20pxの `--map-here` の丸、白い縁3px、まわりに薄い青の輪。
- タイマーが動いているあいだは、停めた場所に車の印（`--map-ok` のしずく形、白いアイコン）を出す。

## 5. メイン画面

上から順に：

1. **検索欄**（左16px・上は safe-area + 12px、高さ52px、角丸14px、`--surface`、`--shadow-ctl`）。虫めがね＋「行き先・駅名で探す」。国土地理院の地名検索。
   - 空欄で押すと「エリアへ移動」（札幌・東京・神奈川・京都・大阪）と「最近」（最近探した5件）を出す。エリアを選ぶと、全域を収めるのではなく、その都道府県で区間がいちばん集まっているところ（半径1.5km にいちばん多くの区間がある区間）を中心に、ズーム14で見せる（東京は神田・日本橋のあたり）。
   - 候補には、その場所の1km以内の区間の数を添える。区間のある都道府県の地名を先に出す。
2. **ⓘ（インフォメーション）ボタン**（検索欄の右、52px角・角丸14px・`--surface`・丸で囲んだ「i」の線のアイコン 26px、`aria-label="ヘルプ・このアプリについて"`）。押すと下からメニュー：よくある質問（開いて読む形）、このアプリについて（データ・地図・検索の出典）、お問い合わせ・運営。
3. **右下の丸ボタン**（48px・`--surface`・カードの上）：有料プランの販売を始めたら一番上に**お気に入り**の★（pro-ads.md §15.2）。その下が**タイマー**（ストップウォッチのアイコン。有料プランの機能。無料のときは鍵が付き、押すと説明のシート。pro-ads.md §15.3。動いているあいだは残り時間：緑の地に「あと」「42分」、残り10分を切ったら赤の地、時間を過ぎたら赤の地に「超過」「−5分」。押すとタイマー §9）、下が現在地へ。
4. **カードの列**（下から16px）：横スクロール＋`scroll-snap`。カード幅330px（狭い画面では 画面幅−48px）、間10px、左16px。次のカードが少し見える。

チップ（日時の指定・「緑だけ」）は置かない。

### 5.1 カードの中身（3段・高さ180pxまで）

```
[P] 池尻一丁目                          ┌─────┐  ← Pの色で状態（緑・赤・グレー）
                                         │¥ 300円│  ← 料金は場所の右の枠
                                         └─────┘
┌──────────────────────────────────────┐
│      🕘             ⏱             📅        │
│  9:00–19:00        1時間       日・祝、1/1–3  │
│   利用時間        最大時間        除外日      │
└──────────────────────────────────────┘
   ↑ A・B・C は同じ幅
[ ➤ ここへ行く        ] [        詳細        ]
```

- **大きさ**：内側の余白14px、行の間6px、高さは最大180px（いまは177px）。390px幅のスマホで、地図が画面の高さの7割以上見えること。
- **位置**：カードは横のまん中にそろえる（幅330px、狭い画面では 画面幅−48px）。両どなりのカードが同じだけ少し見える。めくると、次のカードがまん中で止まる。
- 1段目：Pアイコン（26px角・角丸7px・状態の色の地に白い「P」）、区間名（20px/700、長いときは末尾を「…」）、有料プランの販売中は区間名のすぐ右にお気に入りの星（見せるだけ。登録済みは黒い★、未登録は白い☆。登録は詳細で。pro-ads.md §15.2）。右端に**料金の枠**（`--surface-2` 地・角丸10px・16px/700、左に詳細と同じ円のアイコン（16px・`--muted`）、例「¥ 300円」。料金の無い区間は枠を出さない）。「〜まで」「〜から」のバッジはカードには出さない（状態はPの色。時刻は詳細で見る）。
- 2段目：左から **A 利用時間・B 最大時間・C 除外日** を**同じ幅**（3等分）で。詳細（§7）の3つの数字と同じ形で、上に線のアイコン（時計・ストップウォッチ・カレンダー）、真ん中に値（14px/700、除外日が7文字以上のときは12px、はみ出したら「…」）、下に見出し（10px・`--muted`）。`--surface-2` 地の1枚の枠。
  - 利用時間：`z.hours`。時間不明の区間は「現地で確認」。
  - 除外日：制限事項を短く（「日曜・休日を除く」→「日・祝」、「土・日曜、休日を除く」→「土・日・祝」、「1月1日〜3日を除く」→「1/1–3」）。無ければ「なし」、時間不明の区間は「現地で確認」。正式な文言は詳細に出す。
- 3段目：ボタン（高さ48px）。「ここへ行く」（`--ink` 地に白い文字・矢印のアイコン）と「詳細」（`--chip-2` 地）を**同じ幅**で並べる。
- 赤・グレーの区間は、区間名・料金・値を `--ink-2` に落とす。
- バッジ（詳細・お気に入りの一覧・「ここへ行く」のシートで使う）：緑は `--ok` 地に白文字＋時計のアイコン。赤は `--no-wash` 地に `--no` 文字。グレーは `--off-wash` 地に `--ink-2` 文字。
- カードを押す・横にめくると、その区間を選ぶ。めくったときは、区間が地図の端に近いときだけ地図を少し動かす。
- 「ここへ行く」→ §8。「詳細」→ §7。

### 5.2 並び順と件数

- 起点：地図の見えている範囲のまん中（行き先があるときは行き先）。
- 起点から区間の線までの最短距離が `NEAR_M`（1km）以内の区間。最大 `LIST_MAX`（40）件。
- 緑を近い順、その後に赤とグレーをまとめて近い順。
- 「徒歩◯分」は出さない（直線の距離からの目安で、実際に歩く時間と合わないため）。距離は並び順にだけ使う。
- 地図を動かすと並べ直す（区間を押して地図が動いたときは並べ直さない）。
- 近くに緑がないとき（夜など）：地図は赤（と時間不明のグレー）だけになり、カードは赤の区間を近い順に出す。ボタンはほかと同じ「ここへ行く」「詳細」。「0区間」などの大きな表示は出さない。
- 1km以内に区間がないとき：カード1枚に「この近く（1km以内）には区間がありません。いちばん近い区間まで ◯km」と「いちばん近い区間へ」のボタン（文字が切れない幅）。

### 5.3 広い画面（761px以上）

カードを左の列（幅400px）に縦に並べる。検索欄と「？」ボタンは地図の上（左列の右）に置く。選んだカードには `--ink` の2pxの輪。

## 6. 行き先を入れたとき

- 地名検索で候補を選ぶと「行き先モード」：検索欄に短い名前（都道府県と区市町村を省く。例「銀座四丁目」）を太字で出し、左に「戻る」矢印（行き先を消して前の場所へ）、右に「×」（行き先を消す）。
- 行き先に黒い丸の印（白い旗のアイコン）と、下に黒い札で名前。
- 行き先を中心に半径400mの破線の円（`--map-pick-edge`）と、円の上に白い札「半径400m」。
- カードの上に `--surface` の小札「銀座四丁目の近く **12か所**（近い順）」。
- 並び順の距離は、区間から行き先までで測る（地図を動かしても行き先から）。詳細には距離・徒歩の時間を出さない。

## 7. 区間の詳細

- スマホ：下からシート（`--surface`、上の角丸24px）。**高さは中身に合わせ、390px幅のスマホでスクロールせずに全部が収まる**ように詰める（余白16px・行の間10px）。上に残る地図（最低72px）に、選んだ区間を中央に。左上の丸い「戻る」ボタンは置かない。広い画面では左の列にシートを出す。
- **閉じ方は2つ**：シート右上の「×」（40pxの丸、`--chip-2` 地）、端末の「戻る」（Android の戻るボタン・iPhone のスワイプ）。開くときに履歴を1つ積み、どれで閉じても地図の画面に戻る（ページからは出ない）。
- シートの中身：
  1. 小さく「東京都中央区 · パーキング・メーター」、大きく区間名（22px/700）、右にお気に入りの☆（プレミアム）。徒歩の時間は出さない。「21:00まで」「1回 最大1時間」などの状態の帯は出さない
  2. **3つの数字**：利用時間／最大／料金。上に線のアイコン（時計・ストップウォッチ・円）、真ん中に数字（17px/700）、下にラベル（11px、`--muted`）。`--surface-2` 地の1枚の枠。
  3. **利用できる時間**：曜日ごとの時間が全部同じなら「毎日 9:00–21:00」の1行。違うときは「月〜土」「日・祝」（または「月〜金」「土」「日・祝」）の行で、使えない行は「利用不可」。きょうの行の時間は緑。その下に除外を「、」でつないで1行に（「日曜・休日を除く、1月1日〜3日を除く」など。12px、`--ink-2`、アイコンなし）。
  4. **地図アプリで行き方を見る**：「Apple マップ」「Google マップ」を**横に2つ**（同じ幅・高さ48px）。並びは §8 のシートと同じ。押すとその地図で経路を開く（覚えた地図は使わず、いつも両方を出す）。
  5. 注意（アイコン付き、12px）：「時間外は、ほとんどの区間で駐車禁止です。現地の標識・メーターの表示が優先されます。」
  6. **区間の情報**：車種、路線・区間・枠数（大阪など）、標章車専用の枠、区間番号（東京）。項目は横に続けて並べる（12px）。
  7. 出典ラベル（`--off-wash` の札のすぐ右に文字を続ける。12px。pro-ads.md §22）：
     - 東京：`[公開データ]` 警視庁のオープンデータ（東京都オープンデータカタログ）をもとに Tessera Studio が作成。CC BY 4.0（リンク）
     - 京都：`[公開データ]` 京都府警察ホームページの情報をもとに Tessera Studio が作成。元のページ（リンク）
     - 札幌：`[公開データ]` 北海道警察の情報をもとに作成
     - 大阪：`[おおよその位置]` 大阪府警察の資料をもとに作成
     - 神奈川など時間不明：`[時間は現地で確認]` 神奈川県警察の情報をもとに作成
- 住所がない区間は、開いたときに国土地理院で逆引きして区間名にする。

## 8. 「ここへ行く」

- 初回だけ下からシートを出す（地図は暗く）：
  - 見出し「銀座三丁目へ案内します」
  - 「車で約6分 · 14:08ごろ着」＋バッジ（緑「21:00まで」など）
    - 所要時間の目安：現在地（なければ起点）からの直線距離×1.4 を時速20kmで割る（分、切り上げ）。
    - 着くころに時間外になるときは、赤いバッジ「着くころには時間外」。
  - 「どの地図で案内しますか」：行が2つ（58px、`--surface-2` 地、汎用の地図アイコン＋右に「›」。各社のロゴは使わない）。
  - チェックボックス「次からはこの地図ですぐ開く」（初期オン）
  - 「やめる」
- 選んだ地図を `localStorage` に覚え、2回目からはシートを出さずに直接開く。
- 並び：iPhone/iPad は Apple を上、それ以外は Google を上（§7 の2行も同じ）。
- 開くURL（目的地は区間の `z.center`）。アプリでは地図アプリを直接開く（@capacitor/app-launcher。§7 の2行も同じ）：
  - Apple：`maps://?daddr=${lat},${lng}&dirflg=d`（Apple マップのアプリ）
  - Google：Google マップのアプリが入っていれば `comgooglemaps://?daddr=${lat},${lng}&directionsmode=driving`、入っていなければ `https://www.google.com/maps/dir/?api=1&destination=${lat},${lng}&travelmode=driving`（Safari で開く）。アプリの有無を確かめるため、`Info.plist` の `LSApplicationQueriesSchemes` に `comgooglemaps`
  - ブラウザで開いたとき（確認用）は、Google は上の https、Apple は `https://maps.apple.com/?daddr=${lat},${lng}&dirflg=d`
- カードのボタンは「ここへ行く」のまま切り替えない。

## 9. タイマー

右下のタイマーボタンから開く**カード**。スマホでは、上は検索欄の下半分にかかり（検索欄の縦のまん中から）、下はカードの上から2/3までかかる。**高さは中身に合わせ**（下をカードの2/3の位置にそろえ、上は検索欄の縦のまん中まで）、390px幅のスマホでスクロールせずに収まるように詰める。左右16px、角丸18px、影付き。広い画面では地図の側（左の列の右）に幅460pxで出す。**開いているあいだは、うしろに薄い幕を敷き、ほかのボタン・カード・地図は押せない。** 右上の「∨」（区間名の横、40pxの丸、`--chip-2` 地。または Esc）で閉じる。

- 上：状態の札、区間名（21px/700）、「東京都中央区 · パーキング・メーター」
  - 札：止まっているときグレー「タイマー」、動いているとき緑「駐車中」、時間になったら赤（`--no` 地に白文字）「時間切れ」。
  - 区間は、選んでいる区間（何も選んでいなければ現在地にいちばん近い区間。動いているときは、スタートした区間）。
- 中央：円（直径は画面の高さに合わせて140〜220px）（太さ16px、地 `--line`）。残りの割合だけ色を付け、時計回りに短くなる。
  - 中に「あと」「42分」（大きく、1時間以上は「1時間5分」）「15:05 まで」。分は切り上げ。
  - **残り10分を切ったら、円の残りと数字を赤（`--no`）にする。**
  - 時間になったら円を空にし、赤で「時間です」、その下に**過ぎた時間をマイナスで**「−12分」（1分未満は「−30秒」、1時間以上は「−1時間5分」）、さらに下に「15:00 に終了」。
  - 止まっているときは円をいっぱいにして「最大」「1時間」（その区間の最大時間）。
- 円のすぐ下に「スタート」「ストップ」（下の説明）。その下に2つの小枠：「停めた時刻 14:05」「最大 · 料金 1時間 · 300円」
- 通知の切り替え：「終わる10分前に知らせる」（オン／オフ）、小さく「画面を閉じていても届きます（10分前と時間）」。Pro の販売を始めたら Pro の機能（無料のときは鍵が付き、押すと購入シート。pro-ads.md §15.3）
- 下のボタン：
  - 円のすぐ下に横に2つ：「スタート」（緑・再生のアイコン）と「ストップ」（`--ink`・四角のアイコン）。動いている間はスタートを、止まっている間はストップを薄くして押せなくする。
  - その下に「車の場所を確認」（`--chip-2`・ピンのアイコン）：タイマーを閉じ、スタートした時点の現在地（取れなければ区間の中心）に地図を寄せる。
  - 一番下に小さく「メーター・チケットに表示された時刻が優先です」
- 状態は `localStorage` に保存（`{zoneId, startedAt, limitMin, carLatLng, notified}`）し、再読み込みしても続く。最大時間が分からない区間は60分。
- 通知：iPhone の通知（@capacitor/local-notifications）を、スタートしたときに2つ予約する。「あと10分です」（終わる10分前）と「時間です」（時間になったとき）。アプリを閉じていても、画面がロックされていても届き、アプリを開いているときも上に出す。ストップ・通知をオフ・有料プランでなくなったときは予約を消す。許可は、初めて通知をオンにしたときに聞く。許可されなかったら札「通知が許可されていません。設定アプリの「通知」→「メーターマップ」で許可できます」。

## 10. 開いたとき・現在地

- 開いたらすぐ（区間データの読み込みを待たずに）現在地を取りにいく。まずおおまかな位置で寄せ、あとから届く正確な位置が150m以上ずれていれば、開いてから30秒のあいだだけ寄せ直す。現在地は地図の見えている範囲のまん中に来る。
- 30分以内に取れた現在地があれば、そこから始める。なければ前回見ていた場所、それもなければ銀座。
- 人が地図を動かしたら、それ以降は勝手に動かさない。
- 右下の現在地ボタンで、いつでも現在地へ寄せる（行き先モードは外す）。

## 11. 変えないもの

- データ（`data/zones.geojson`、`zones.js`、`data/holidays.json`）と判定ロジック（`avail()`、`nextOpen()`、`Zones.openNow()`）
- 地名検索・逆引き（国土地理院）
- `build/stamp.py` でのキャッシュ番号付け（画面のファイルを変えたらコミット前に実行）
