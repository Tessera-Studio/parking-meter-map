## 1. 方針

- **地図が主役。** 画面のほとんどを地図にし、上に検索欄とタイマーボタン、下（広い画面では左）に区間のカードだけを置く。カードは地図を隠さない大きさにする（§5）。
- **いつも明るい。** 端末がダークテーマでも、地図・カード・シート・ボタンとも明るい配色のまま。ダークテーマ用の配色は持たない。
- **状態は色だけで伝える。** 緑＝いま使える区間、赤＝時間外の区間、グレー＝時間不明の区間。選んだ区間だけ黄。
- **区間は道路に沿った線で見せる。** 線はいつも出す。Pマークは選んだ区間と、十分に寄った地図のときだけ（地図の上に物を増やさない）。
- **「何時まで」はカードのバッジに任せる。** 地図の上には時刻の札を出さない。
- **判定はいつも「いま」。** 日時を指定する機能は置かない。1分ごとに見直す。
- 見た目：白い角丸カード＋薄い影。黒い枠線と四角い部品は使わない。オレンジは使わない（赤と紛らわしいため）。

## 2. 文言のルール（重要）

- 「いま停められる」「停められます」「停められない」「停められません」は**画面のどこにも出さない**。
- 緑の区間のバッジ：**終わりの時刻だけ**。例「21:00まで」
- 時間外の区間のバッジ（赤）：**次に使える時刻だけ**。例「あす 9:00から」「土曜 9:00から」。見つからないときは「冬期休止中」
- 時間不明（`avail()==='unk'`）のバッジ（グレー）：「時間は現地で確認」
- 詳細の時間表の見出しは「利用できる時間」、使えない行は「利用不可」
- 「あと◯分で時間外」のような表示は出さない（タイマーの残り時間は別。§9）

  --surface-2:#F5F4F1;   /* カード・シート内の小さな枠 */

  --line:#ECEAE4;        /* 区切り線・タイマーの円の地 */
  --ink:#1C1D1F;  --on-ink:#FFFFFF;
  --ink-2:#4A4D52;
  --muted:#6B6F75;
  --ok:#1E7F4A;   --on-ok:#FFFFFF;   /* 緑（バッジ・状態・スタート） */
  --no:#C8372D;   --on-no:#FFFFFF;   /* 赤（バッジの文字・時間切れ） */
  --no-wash:#FBE4E2;                 /* 赤のバッジ・状態の地 */
  --off:#A3A8AE;                     /* グレー */
  --off-wash:#E6E7E9;                /* グレーのバッジ・状態の地 */
  --here:#2F6FDB;                    /* フォーカスの輪 */

  /* 地図の上に描くもの */

  --map-off:#A3A8AE;     /* 時間不明の線・P */
  --map-pick:#F2B300;    /* 選んだ区間の線（緑・赤・グレー・現在地の青とぶつからない色） */

  --r-card:18px; --r-ctl:14px; --r-btn:12px; --r-badge:8px;

- `color-scheme: light`。`prefers-color-scheme: dark` で色を変える処理は置かない。
- 数字は `font-variant-numeric: tabular-nums`。

## 4. 地図

### 4.1 下地

- OpenFreeMap（OpenMapTiles）のベクトル地図を MapLibre GL JS で描く（`basemap.js`。ライブラリは `vendor/` に同梱、鍵は不要）。配色は `basemap.js` の明るい配色だけ。
- 右下の丸ボタン（レイヤーのアイコン）で「シンプル」と「詳しい」を切り替える。選んだほうを `localStorage` に覚える。
  - シンプル：地名・駅名・大きな道の名前だけ。区間の線とPマークが目立つ。
  - 詳しい：建物・施設名・細い道の名前も出す。
- 駅名・町名・大きな施設名のラベルは、どちらでも残す（場所の手がかり）。
- WebGL が使えない、または地図が読めない（8秒たっても1枚も届かない・その前に失敗した）ときは、国土地理院の淡色地図（画像）に切り替える。
- 地図に CSS の filter（暗くする・色を反転する）はかけない。
- 出典は地図の右下（区間データ・OpenFreeMap・OpenMapTiles・OpenStreetMap、画像の地図のときは地理院タイル）。

### 4.2 区間の線（いつも出す）

| 状態 | 線 |
|---|---|
| 緑（`ok`） | 太さ6pxの `--map-ok`、下に10pxの白い縁 |
| 赤（`no`） | 太さ4pxの `--map-no`、縁なし |
| 時間不明（`unk`） | 太さ4pxの `--map-off` の破線（4 6） |
| **選んだ区間** | 太さ8pxの `--map-pick`、下に12pxの `--map-pick-edge` の縁。状態に関係なく同じ色 |

- 選んだ区間の状態（緑・赤・グレー）は、Pマークの色とカードのバッジで伝える。線の色は「選んでいる」ことだけを表す。
- 重なり順：時間不明 → 赤 → 緑 → 選んだ区間。赤は緑より細くする。
- 細い線にも押せるよう、見えない太い当たり判定（18px）を重ねる。
- `SMALL_ZOOM`（14）より引いた地図では線を細くする（緑4px・赤2px・時間不明2px、白い縁なし）。線は省かない。

### 4.3 Pマーク

| 地図の縮尺 | Pマーク |
|---|---|
| `DETAIL_ZOOM`（17）未満 | **選んだ区間だけ** |
| `DETAIL_ZOOM` 以上 | 全区間に小さいPマーク＋選んだ区間に大きいPマーク |

- 地の色：緑なら `--map-ok`、時間外なら `--map-no`、時間不明なら `--map-off`。中の「P」は白。
- 選んだ区間：32px角・角丸9px・白い縁3px・`--shadow-ctl`・下に白い小さな三角。`z.center` に置く（Leaflet の `divIcon`）。
- 寄ったときの小さいP：18px角・角丸5px・白い縁2px。重なり順は 時間不明 → 赤 → 緑。押せる。
- **地図の上に時刻の札（「〜21:00」など）は出さない。**

### 4.4 押したとき・そのほか

- 線・Pのどちらを押しても、その区間を選び、カードの列をそのカードまで動かし、その区間を地図の見えている範囲（上の検索欄と下のカード、広い画面では左の列を除いた部分）のまん中に動かす。カードの並びは変えない。
- カードの列を自動で動かしている途中は、途中のカードを選び直さない（人がカードに触れたら、その操作を優先）。
- 現在地：20pxの `--map-here` の丸、白い縁3px、まわりに薄い青の輪。
- タイマーが動いているあいだは、停めた場所に車の印（`--map-ok` のしずく形、白いアイコン）を出す。

## 5. メイン画面

上から順に：

1. **検索欄**（左16px・上は safe-area + 12px、高さ52px、角丸14px、`--surface`、`--shadow-ctl`）。虫めがね＋「行き先・駅名で探す」。国土地理院の地名検索。
   - 空欄で押すと「エリアへ移動」（札幌・東京・神奈川・京都・大阪）と「最近」（最近探した5件）を出す。
   - 候補には、その場所の1km以内の区間の数を添える。区間のある都道府県の地名を先に出す。
2. **タイマーボタン**（検索欄の右、52px角・角丸14px・`--surface`・時計のアイコン、`aria-label="タイマー"`）。動いているあいだは右上に緑の点。押すとタイマー（§9）。
3. **右下の丸ボタン**（48px・`--surface`・カードの上）：上が地図の切り替え（§4.1）、下が現在地へ。
4. **カードの列**（下から16px）：横スクロール＋`scroll-snap`。カード幅330px（狭い画面では 画面幅−48px）、間10px、左16px。次のカードが少し見える。

チップ（日時の指定・「緑だけ」）は置かない。

### 5.1 カードの中身（4行・高さ180pxまで）

```
[P] 有楽町二丁目                 [きょう 9:00から]   ← Pの色とバッジで状態
メーター · 徒歩1分 · 最大1時間 · 300円        1/40
9:00–19:00 · 日曜・休日、1/1–3 を除く
[ ➤ ここへ行く      ] [      詳細      ]
```

- **大きさ**：内側の余白14px、行の間6px、高さは最大180px。390px幅のスマホで、地図が画面の高さの7割以上見えること。
- 1行目：Pアイコン（26px角・角丸7px・状態の色の地に白い「P」）、区間名（20px/700、長いときは末尾を「…」）、右端にバッジ。
- 2行目：種類・徒歩◯分・最大・料金を「·」でつなぐ（13px、`--muted`）。右端に件数「1/40」。
- 3行目：利用時間と除外を1行で（13px、`--muted`、はみ出したら「…」）。除外がなければ「毎日 9:00–21:00」。除外があれば「9:00–19:00 · 日曜・休日、1/1–3 を除く」。時間不明の区間はこの行を出さない。
- 4行目：ボタン2つを**同じ幅**で横に並べる（高さ44px）。「ここへ行く」（`--ink` 地に白い文字・矢印のアイコン）と「詳細」（`--chip-2` 地）。
- バッジ：緑は `--ok` 地に白文字＋時計のアイコン。赤は `--no-wash` 地に `--no` 文字。グレーは `--off-wash` 地に `--ink-2` 文字。
- 赤・グレーの区間は、区間名を `--ink-2` に落とす。
- カードを押す・横にめくると、その区間を選ぶ。めくったときは、区間が地図の端に近いときだけ地図を少し動かす。
- 「ここへ行く」→ §8。「詳細」→ §7。

### 5.2 並び順と件数

- 起点：地図の見えている範囲のまん中（行き先があるときは行き先）。
- 起点から区間の線までの最短距離が `NEAR_M`（1km）以内の区間。最大 `LIST_MAX`（40）件。
- 緑を近い順、その後に赤とグレーをまとめて近い順。
- 「徒歩◯分」＝距離(m)÷80 を切り上げ。
- 地図を動かすと並べ直す（区間を押して地図が動いたときは並べ直さない）。
- 近くに緑がないとき（夜など）：地図は赤（と時間不明のグレー）だけになり、カードは赤の区間を近い順に出す。ボタンはほかと同じ「ここへ行く」「詳細」。「0区間」などの大きな表示は出さない。
- 1km以内に区間がないとき：カード1枚に「この近く（1km以内）には区間がありません。いちばん近い区間まで ◯km」と「いちばん近い区間へ」のボタン。

### 5.3 広い画面（761px以上）

カードを左の列（幅400px）に縦に並べる。検索欄とタイマーボタンは地図の上（左列の右）に置く。選んだカードには `--ink` の2pxの輪。

## 6. 行き先を入れたとき

- 地名検索で候補を選ぶと「行き先モード」：検索欄に短い名前（都道府県と区市町村を省く。例「銀座四丁目」）を太字で出し、左に「戻る」矢印（行き先を消して前の場所へ）、右に「×」（行き先を消す）。
- 行き先に黒い丸の印（白い旗のアイコン）と、下に黒い札で名前。
- 行き先を中心に半径400mの破線の円（`--map-pick-edge`）と、円の上に白い札「徒歩5分」。
- カードの上に `--surface` の小札「銀座四丁目の近く **12か所**（近い順）」。
- カードの距離は「銀座四丁目まで 徒歩3分」（区間から行き先まで）。地図を動かしても行き先から測る。

## 7. 区間の詳細

- スマホ：上の約236pxは地図（選んだ区間を中央に）、左上に丸い「戻る」ボタン。その下にシート（`--surface`、上の角丸24px、スクロール）。広い画面では左の列にシートを出す。
- **閉じ方は3つ**：左上の「戻る」、シート右上の「×」（40pxの丸、`--chip-2` 地）、端末の「戻る」（Android の戻るボタン・iPhone のスワイプ）。開くときに履歴を1つ積み、どれで閉じても地図の画面に戻る（ページからは出ない）。
- シートの中身：
  1. 小さく「東京都中央区 · パーキング・メーター」、大きく区間名（28px/700）、右に「徒歩 2分」
  2. **状態**：緑のときは `--ok` 地に白文字で「21:00まで」（24px/700）と「1回 最大1時間」。時間外は `--no-wash` 地に `--no` 文字で「あす 9:00から」。時間不明は `--off-wash` 地で「時間は現地で確認」と「県警の公開情報に時間・曜日がありません」。
  3. **3つの数字**：利用時間／最大／料金。上に線のアイコン（時計・ストップウォッチ・円）、真ん中に数字（20px/700）、下にラベル（12px、`--muted`）。`--surface-2` 地の1枚の枠。
  4. **利用できる時間**：曜日ごとの時間が全部同じなら「毎日 9:00–21:00」の1行。違うときは「月〜土」「日・祝」（または「月〜金」「土」「日・祝」）の行で、使えない行は「利用不可」。きょうの行の時間は緑。その下に除外を1行ずつ（「日曜・休日を除く」「1月1日〜3日を除く」など。13px、`--ink-2`、アイコンなし）。
  5. 注意（アイコン付き、13px）：「時間外は、ほとんどの区間で駐車禁止です。現地の標識・メーターの表示が優先されます。」
  6. **区間の情報**：車種、路線・区間・枠数（大阪など）、標章車専用の枠、区間番号（東京）。
  7. 出典ラベル（`--off-wash` の札＋文字）：
     - 東京：`[公式データ]` 警視庁 オープンデータ（2026年4月）
     - 大阪：`[おおよその位置]` 大阪府警察の資料から作成
     - 神奈川など時間不明：`[時間は現地で確認]` 神奈川県警察
     - 札幌・京都：`[公式データ]` 北海道警察／京都府警察の公開情報
  8. **地図アプリで経路を見る**：「Apple マップ」「Google マップ」の2行。§8 のシートと**同じ見た目・同じ大きさ・同じ並び**。押すとその地図で経路を開く（覚えた地図は使わず、いつも両方を出す）。
- 住所がない区間は、開いたときに国土地理院で逆引きして区間名にする。

## 8. 「ここへ行く」

- 初回だけ下からシートを出す（地図は暗く）：
  - 見出し「銀座三丁目へ案内します」
  - 「車で約6分 · 14:08ごろ着」＋バッジ（緑「21:00まで」など）
    - 所要時間の目安：現在地（なければ起点）からの直線距離×1.4 を時速20kmで割る（分、切り上げ）。
    - 着くころに時間外になるときは、赤いバッジ「着くころには時間外」。
  - 「どの地図で案内しますか」：行が2つ（58px、`--surface-2` 地、汎用の地図アイコン＋右に「›」。各社のロゴは使わない）。
  - チェックボックス「次からはこの地図ですぐ開く」（初期オン）
  - 「やめる」
- 選んだ地図を `localStorage` に覚え、2回目からはシートを出さずに直接開く。
- 並び：iPhone/iPad は Apple を上、それ以外は Google を上（§7 の2行も同じ）。
- 開くURL（目的地は区間の `z.center`）：
  - Google：`https://www.google.com/maps/dir/?api=1&destination=${lat},${lng}&travelmode=driving`
  - Apple：`https://maps.apple.com/?daddr=${lat},${lng}&dirflg=d`
- カードのボタンは「ここへ行く」のまま切り替えない。

## 9. タイマー

右上の時計ボタンから開く全画面のビュー（地図の上に重ねる）。左上の「∨」で閉じる。

- 上：状態の札、区間名（26px/700）、「東京都中央区 · パーキング・メーター」
  - 札：止まっているときグレー「タイマー」、動いているとき緑「駐車中」、時間になったら赤（`--no` 地に白文字）「時間切れ」。
  - 区間は、スタートした時点で選んでいた区間。何も選んでいなければ現在地にいちばん近い区間。
- 中央：直径260pxの円（太さ16px、地 `--line`）。残りの割合だけ色を付け、時計回りに短くなる。
  - 中に「あと」「42分」（64px/700、1時間以上は「1時間5分」）「15:05 まで」。分は切り上げ。
  - **残り10分を切ったら、円の残りと数字を赤（`--no`）にする。**
  - 時間になったら円を空にし、赤で「時間です」。
  - 止まっているときは円をいっぱいにして「最大」「1時間」（その区間の最大時間）。
- 2つの小枠：「停めた時刻 14:05」「最大 · 料金 1時間 · 300円」
- 通知の切り替え：「終わる10分前に知らせる」（オン／オフ）、小さく「ホーム画面に追加すると、画面を閉じていても届きます」
- 下のボタン：
  - 横に2つ：「スタート」（緑・再生のアイコン）と「ストップ」（`--ink`・四角のアイコン）。動いている間はスタートを、止まっている間はストップを薄くして押せなくする。
  - その下に「車の場所を確認」（`--chip-2`・ピンのアイコン）：タイマーを閉じ、スタートした時点の現在地（取れなければ区間の中心）に地図を寄せる。
  - 一番下に小さく「メーター・チケットに表示された時刻が優先です」
- 状態は `localStorage` に保存（`{zoneId, startedAt, limitMin, carLatLng, notified}`）し、再読み込みしても続く。最大時間が分からない区間は60分。
- 通知：許可があれば、終わる10分前に1回出す。許可がない／使えないときは画面の表示だけ。

## 10. 開いたとき・現在地

- 開いたらすぐ（区間データの読み込みを待たずに）現在地を取りにいく。まずおおまかな位置で寄せ、あとから届く正確な位置が150m以上ずれていれば、開いてから30秒のあいだだけ寄せ直す。現在地は地図の見えている範囲のまん中に来る。
- 30分以内に取れた現在地があれば、そこから始める。なければ前回見ていた場所、それもなければ銀座。
- 人が地図を動かしたら、それ以降は勝手に動かさない。
- 右下の現在地ボタンで、いつでも現在地へ寄せる（行き先モードは外す）。

## 11. 変えないもの
