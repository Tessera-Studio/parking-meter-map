## 1. 方針

- **地図が主役。** 画面のほとんどを地図にし、上に検索とチップ、下に区間のカード（横にめくる）だけを置く。今の「一覧シート（画面の44%）」はやめる。
- **状態は色だけで伝える。** 緑＝その時刻に使える区間、それ以外（時間外・時間不明）はすべてグレー。
- **区間は「道路に沿った線＋Pマーク」で見せる。** 点だけでは場所が分からないため、線は必ず出す。
- 見た目：白い角丸カード＋薄い影。黒い枠線と四角い部品はやめる。アクセントは緑1色。

## 2. 文言のルール（重要）

- 「いま停められる」「停められます」「停められない」「停められません」は**画面のどこにも出さない**。
- 緑の区間のバッジ：**終わりの時刻だけ**。例「21:00まで」
- 時間外の区間のバッジ（グレー）：**次に使える時刻だけ**。例「あす 9:00から」「土曜 9:00から」。見つからないときは「冬期休止中」
- 時間不明（`avail()==='unk'`）のバッジ（グレー）：「時間は現地で確認」
- 詳細の時間表の見出しは「利用できる時間」、使えない行は「利用不可」
- 「あと◯分」の表示（今のオレンジの枠）はやめる

`status()` / `verdict()` / `week()` / `rowHtml()` の文言をこのルールに合わせて書き換えること。

## 3. デザイン・トークン

```css
:root{
  --ground:#ECEAE4;      /* 地図の地の色・画面の地 */
  --surface:#FFFFFF;     /* カード・シート */
  --surface-2:#F5F4F1;   /* カード内の小さな枠（最大・料金など） */
  --chip-2:#F1F1EF;      /* サブボタン（詳細・車の場所を確認） */
  --line:#ECEAE4;        /* 区切り線 */
  --ink:#1C1D1F;
  --ink-2:#4A4D52;
  --muted:#6B6F75;
  --ok:#1E7F4A;          /* 緑。白文字を載せて読める濃さ */
  --off:#A3A8AE;         /* グレーの線・グレーのP */
  --off-wash:#E6E7E9;    /* グレーのバッジの地 */
  --here:#2F6FDB;        /* 現在地 */
  --r-card:18px; --r-ctl:14px; --r-btn:12px; --r-badge:8px;
  --shadow-card:0 4px 18px rgba(0,0,0,.14);
  --shadow-ctl:0 2px 10px rgba(0,0,0,.12);
  --f-body:"Zen Kaku Gothic New","Hiragino Sans",system-ui,sans-serif;
}
```

ダークテーマは、地・カードを暗く（例 `--ground:#141516; --surface:#1E2022; --surface-2:#26292C; --ink:#F2F2F2; --ink-2:#D0D0D0; --muted:#A6A6A6`）、`--ok` は明るめ（`#4FC983`、ただしその上の文字は黒）にする。

文字の大きさ：カードの区間名 22px/700、距離 15px/700、補足 14px、バッジ 13px/700、検索 16px。数字は `font-variant-numeric: tabular-nums`。

## 4. 地図の描き方（`draw()`）

| 状態 | 線 | Pマーク |
|---|---|---|
| 緑（`ok`） | 太さ7pxの `--ok`、下に11pxの白い縁 | 24px角・角丸7px・`--ok` 地に白い「P」・白い縁2px。下に白い小札「〜21:00」（緑の文字） |
| グレー（`no`） | 太さ4pxの `--off` | 20px角・角丸6px・`--off` 地に白い「P」・白い縁2px。札なし |
| 時間不明（`unk`） | 太さ4pxの `--off` の破線（4 6） | グレーのPと同じ |
| 選んだ区間 | 線を9px、下に15pxの `--ink` の縁 | 36px角・白い縁3px・外側に2pxの `--ink` の輪・下に小さな三角 |

- Pマークは区間の `z.center` に置く（Leaflet の `divIcon`）。線もPも押せる。細い線には見えない太い当たり判定（18px程度）を重ねる。
- 重なり順：グレー → 緑 → 選んだ区間。
- `SMALL_ZOOM` より引いた地図では線を省き、Pマークだけ（緑の札も省く）。
- 「緑だけ」チップがオンのときは、グレーと時間不明の線・Pを描かない。
- 下地は淡色地図のままでよいが、**駅名・大きな施設名のラベルは残す**こと（場所の手がかり）。
- 現在地：20pxの `--here` の丸、白い縁3px、まわりに薄い青の輪。

## 5. メイン画面

上から順に：

1. **検索欄**（左16px・右78px・上は safe-area + 12px、高さ52px、角丸14px、白、`--shadow-ctl`）。虫めがねアイコン＋プレースホルダ「行き先・駅名で探す」。今の国土地理院の地名検索をそのまま使う。
2. **タイマーボタン**（検索欄の右、52px角・角丸14px・白・時計アイコン、`aria-label="タイマー"`）。押すとタイマー画面（§9）。
3. **チップの列**（検索欄の下 10px）：
   - 「いま 14:00 ▾」：黒地に白。押すと日時の選択（今の `whenDay`/`whenHour` と同じ内容）を出す。日時を指定中は「あす 10:00 ▾」のように表示。
   - 「緑だけ」：白地。左に緑の短い線。オンで黒地に白。
4. **現在地ボタン**：右下、カードの上。48pxの白い丸。
5. **カードの列**（下から28px）：横スクロール＋`scroll-snap`。カード幅330px、間10px、左16px。次のカードが少し見える。

**地図の切り替えボタン（シンプル／詳しい）** はキャンバスに無いが機能は残す。現在地ボタンの上に同じ大きさの白い丸ボタン（レイヤーのアイコンのみ）として置く。

### カードの中身

```
[21:00まで]                        1 / 4      ← バッジ（緑 or グレー）と件数
銀座三丁目                      徒歩 2分      ← 区間名（町名）と距離
最大1時間 · 300円 · メーター                  ← terms＋種類
[  ➤ ここへ行く  ] [ 詳細 ]
```

- バッジ：緑は `--ok` 地に白文字＋時計アイコン。グレーは `--off-wash` 地に `--ink-2` 文字。
- グレーの区間のカードは、区間名・距離も `--ink-2` に落とす。
- 「徒歩◯分」＝距離(m)÷80 を切り上げ。距離は地図の中心（行き先があるときは行き先）から区間の線までの最短距離（今の `nearest()`）。
- 並び順：緑を近い順、その後にグレーを近い順。件数は今の `NEAR_M`（1km）以内、最大 `LIST_MAX`。
- カードを横にめくると、その区間を選んだ状態にして地図を少し動かす。地図の線やPを押すと、そのカードまでカルーセルを動かす。
- 「ここへ行く」→ §8。「詳細」→ §7。

### 広い画面（761px以上）

カードを左の列（幅400px）に縦に並べる。上の検索欄・チップ・タイマーボタンは地図の上（左列の右）に置く。

## 6. 行き先を入れたとき

- 地名検索で候補を選ぶと「行き先モード」：検索欄に名前を表示し、左を「戻る」矢印、右に「×」（行き先を消す）。
- 行き先に黒い丸のマーカー（白い旗アイコン）と、下に黒い札で名前。
- 行き先を中心に半径400mの破線の円と、円の上に白い札「徒歩5分」。
- カードの上に白い小札「歌舞伎座の近く **5か所**（近い順）」。
- カードの距離表示は「歌舞伎座まで 徒歩3分」（区間から行き先まで）。

## 7. 区間の詳細

- 上の約236pxは地図（選んだ区間を中央に）。左上に白い丸の「戻る」ボタン。
- その下に白いシート（上の角丸24px）。中身：
  1. 小さく「東京都中央区 · パーキング・メーター」、大きく区間名（28px/700）、右に「徒歩 2分」
  2. **状態ブロック**：緑のときは `--ok` 地に白文字で「21:00まで」（24px/700）と「1回 最大1時間」。時間外は `--off-wash` 地で「あす 9:00から」。時間不明は「時間は現地で確認」と「県警の公開情報に時間・曜日がありません」。
  3. 3つの小枠：最大／料金／車種
  4. 「利用できる時間」：曜日ごとの時間が全部同じなら「毎日 9:00–21:00」の1行にまとめる。違うときだけ曜日別の行。正月・冬期など使えない期間は小さい灰色の行で「利用不可」。
  5. 注意（アイコン付き、13px）：「時間外は、ほとんどの区間で駐車禁止です。現地の標識・メーターの表示が優先されます。」
  6. 出典ラベル：
     - 東京：`[公式データ]` 警視庁 オープンデータ（2026年4月）
     - 大阪：`[おおよその位置]` 大阪府警察の資料から作成
     - 神奈川など時間不明：`[時間は現地で確認]` 神奈川県警察
     - 札幌・京都：`[公式データ]` 各警察の公開情報
  7. ボタン：「Googleマップで経路を見る」（緑）、その下に文字リンク「Appleマップで開く」

## 8. 「ここへ行く」

- 初回だけ下からシートを出す（地図は暗く）：
  - 見出し「銀座三丁目へ案内します」
  - 「車で約6分 · 14:08ごろ着」＋緑バッジ「21:00まで」
    - 所要時間の目安：直線距離×1.4 を時速20kmで割る（分、切り上げ）。
    - 到着予想が終わりの時刻を過ぎるときは、バッジをグレーにして「着くころには時間外」。
  - 「どの地図で案内しますか」：行が2つ（56–60px、`--surface-2` 地）「Apple マップ」「Google マップ」。アイコンは汎用の地図アイコンで、各社のロゴは使わない。
  - チェックボックス「次からはこの地図ですぐ開く」（初期オン）
  - 「やめる」
- 選んだ地図を `localStorage` に覚え、2回目からはシートを出さずに直接開く。詳細画面のリンクは常に両方使える。
- 既定の並び：iPhone/iPad は Apple を上、それ以外は Google を上。
- 開くURL（目的地は区間の `z.center`）：
  - Google：`https://www.google.com/maps/dir/?api=1&destination=${lat},${lng}&travelmode=driving`
  - Apple：`https://maps.apple.com/?daddr=${lat},${lng}&dirflg=d`
- **カードのボタンは「ここへ行く」のまま切り替えない**（区間に着いても「停めた」などには変えない）。

## 9. タイマー

右上の時計ボタンから開く全画面のビュー（ページ遷移ではなく、地図の上に重ねる）。左上の「∨」で閉じる。

- 上：状態の札（動いているとき緑「駐車中」、止まっているときグレー「タイマー」）、区間名（26px/700）、「東京都中央区 · パーキング・メーター」
  - 区間は、スタートした時点で選んでいた区間。何も選んでいなければ現在地にいちばん近い区間。
- 中央：直径260pxの円（太さ16px、地 `--line`、残りを `--ok`）。中に「あと」「42分」（64px/700）「15:05 まで」。
  - 止まっているときは円をいっぱいにして「1時間」と、その区間の最大時間を出す。
- 2つの小枠：「停めた時刻 14:05」「最大 · 料金 1時間 · 300円」
- 通知の切り替え：「終わる10分前に知らせる」（オン／オフ）、小さく「ホーム画面に追加すると、画面を閉じていても届きます」
- 下のボタン：
  - 横に2つ並べる：**「スタート」**（緑・再生アイコン）と **「ストップ」**（黒・四角アイコン）。動いている間はスタートを薄くして押せなくし、止まっている間はストップを薄くする。
  - その下に「車の場所を確認」（`--chip-2` 地・ピンのアイコン）：タイマー画面を閉じ、スタートした時点の現在地（取れなければ区間の中心）に地図を寄せて、車のマーカーを出す。
  - 一番下に小さく「メーター・チケットに表示された時刻が優先です」
- 「出庫した」ボタンは置かない。
- 状態は `localStorage` に保存（`{zoneId, startedAt, limitMin, carLatLng}`）し、再読み込みしても続く。最大時間が分からない区間は60分。
- 通知：`Notification` の許可があれば、終わる10分前に1回出す。許可がない／使えないときは画面上の表示だけ。
- 時間になったら円を空にし、「時間です」と出す（色はグレー）。

## 10. 近くに緑がないとき（夜など）

- 地図はすべてグレーの線とグレーのP。
- カードはグレーの区間を近い順に出す（バッジ「あす 9:00から」）。
- カードのボタンは「あす 9:00 で見る」（黒地。押すと `state.at` をその時刻にして再描画）と「近くの駐車場 ↗」（`--chip-2`。Google マップで `駐車場` を地図の中心付近で検索するURLを開く）。
- 「0区間」の大きな表示や「この近くで停められる区間はありません」の文章は出さない。

## 11. 消すもの

- 一覧シート（`.sheet`、`grip`、`sum`、凡例 `key`、`notice`、`renderList()` の今の形）→ カード列に置き換え
- 「あと◯分」のオレンジの枠（`.soon`）
- 黒い1.5pxの枠線、角2pxの部品

## 12. 変えないもの

- データ（`data/zones.geojson`、`zones.js`、`data/holidays.json`）と判定ロジック（`avail()`、`nextOpen()`、`Zones.openNow()`）
- 地名検索・逆引き（国土地理院）
- 最初に見せる場所（現在地 → 前回の場所 → 銀座）
- 出典の表示（地図の右下）
- `build/stamp.py` でのキャッシュ番号付け（画面のファイルを変えたらコミット前に実行）
